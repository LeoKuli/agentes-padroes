# Skills deste repositório

Skills no formato aberto **Agent Skills**: uma pasta por skill, cada uma com um `SKILL.md` (frontmatter YAML com
`name` e `description`, depois as instruções). Ferramentas que leem `.agents/skills/` carregam sozinhas; as que não
leem chegam aqui pelo `AGENTS.md`.

As skills de método, que valem para todos os projetos do dono, moram em um lugar só:
<https://github.com/LeoKuli/agentes-padroes/tree/main/.agents/skills>. Aqui ficam apenas as skills próprias deste
projeto (com caminhos, tabelas e comandos dele).
